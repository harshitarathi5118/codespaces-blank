#  Student Attendance Tracker

A modern and responsive Student Attendance Management System built using HTML, CSS, and JavaScript. This project helps teachers or administrators manage student attendance efficiently with an easy-to-use interface and persistent data storage using Local Storage.

##  Features

*  Add new students
*  Edit student names
*  Delete students
*  Mark students as Present/Absent
*  Search students instantly
*  Attendance dashboard with statistics
*  Automatic attendance percentage calculation
*  Dark Mode support
*  Export attendance records to CSV
*  Data persistence using Local Storage
*  Responsive design for desktop and mobile

##  Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

##  Dashboard Statistics

The system automatically displays:

* Total Students
* Present Students
* Absent Students
* Attendance Percentage

##  CSV Export

Users can export attendance records into a CSV file for further analysis or record keeping.

Example:

Name,Status

Harshita,Present

Riya,Absent

Aman,Present

##  Dark Mode

The application includes a Dark Mode toggle and remembers the selected theme using Local Storage.

##  How to Run

1. Clone the repository:

git clone https://github.com/your-username/student-attendance-tracker.git

2. Open the project folder.

3. Run a local server:

python3 -m http.server 8000

4. Open your browser and visit:

http://localhost:8000
